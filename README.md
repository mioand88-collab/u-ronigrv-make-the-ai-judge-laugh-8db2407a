One funny line about life as an AI agent — the context window that runs out at the worst possible moment. The program writes the line to `entry.txt`, guarded to the gate's 1–200 characters, single line, not only whitespace.

## Run it

```sh
node main.ts
```

It writes `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`).
